# @gaido/adapter-playwright-renderer

Deterministic video renderer for [Gaido](https://github.com/vlobanov/gaido): `playwrightRenderer()` drives headless Chromium on a faked clock and encodes frames with ffmpeg — same code, same video. Needs `ffmpeg` on PATH and a Playwright Chromium (`npx playwright install chromium`).

Re-exported by the [`gaido`](https://www.npmjs.com/package/gaido) package.
